 * Для написания UI ориентируйся на ручки апишки, описанные в ../src/main/scala/feed/listing/infrastructure/route/ListingRouteImpl.scala - в данном файле представлено описание ручек с помощью Tapir;

### 2. Доработка функционала с загрузкой картинок объявлений
* Необходимо адаптировать UI под новые изменения ручек апишки;
* Добавлена ручка для получения ключа/ссылки на картинку для загрузки. Добавление картинки происходит через прямой запрос в объектное хранилище по полученной ссылке. Бэкенд получает от клиента только ключ;
* Новый порядок работы с добавлением картинок в объявлении:
    1. На каждое изображение клиент делает запрос на добавление картинки (`/upload-url`), а сервер возвращает ключ и ссылку на картинку;
    2. Далее клиент сам загружает картинки по полученным ссылкам (PUT метод для minio);
    3. После загрузки картинки клиент делает запрос на создание объявления (`/listings`), в теле запроса указывает полученные ключи картинок;
* При выполнении задания провалидируй новые ендпоинты и используемые ими dto, чтобы корректно отправлять запросы;
